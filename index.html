Surat Pengganti Buku Nenkin

Tempel pesan WhatsApp → otomatis jadi surat siap unduh.

1Tempel pesan WA

Pesan pertama = data pemohon + kaisha 1. Pesan berikutnya (+ Kaisha) hanya menambah tabel perusahaannya. Maksimal 5.

2Rapikan di preview

Klik teks untuk memilih, klik dua kali untuk mengetik. Semua menu edit ada di bar mengambang di atas dokumen. Mode Kotak menggeser dan mengubah ukuran kotak tabel, mode Teks hanya menggeser teks. Seret dari penggaris di tepi halaman untuk membuat garis bantu. Ctrl+Z untuk urungkan. Klik area kosong untuk preview bersih.

3Cek parameter hasil baca pesan

Isi hasil pembacaan pesan WA. Ubah di sini dan preview ikut berubah. Langkah ini boleh dilewati.

4Unduh

Hasil unduhan sama dengan preview. Simpan sesi lewat tombol “Simpan file sesi” atau menu Riwayat.
